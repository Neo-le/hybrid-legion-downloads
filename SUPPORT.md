## 게임 오류·피드백 / Bugs and feedback

앱 버전, 기기 모델·OS 버전, 발생 화면, 재현 순서를 적어 주세요. 스크린샷에 이메일·이름·개인 알림이 보이면 가린 뒤 보내 주세요. 비밀번호, 인증 코드와 결제 정보는 보내지 마세요.

Include the app version, device model/OS, affected screen and steps to reproduce. Hide personal information in screenshots. Never send passwords, authentication codes or payment information.

## 게임 정보 열람·삭제 / Game data access and deletion

설정 → 계정·백업 → 정보·삭제 안내에서 게임 클라우드 기록을 직접 삭제할 수 있습니다. 기기 진행은 유지됩니다. 문의로 요청하려면 요청 내용을 먼저 보내 주세요. 본인 확인에 필요한 정보만 별도로 안내하며 계정 비밀번호나 인증 코드는 요구하지 않습니다.

You can delete game cloud data from Settings → Account & backup → Data & deletion. This keeps local progress. For access or deletion assistance, send the request first; we will explain the minimum ownership verification needed without asking for passwords or authentication codes.

Unity Player Account 자체는 [Unity 계정 삭제 / Unity account deletion](https://player-account.unity.com/delete-account), 해당 계정에 대한 개인정보 요청은 [Unity privacy support](mailto:unity-player-login-privacy@unity3d.com)로 연락하세요.
